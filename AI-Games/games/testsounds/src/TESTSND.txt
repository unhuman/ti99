1986               	; 	' TESTSOUNDS -- a bench for Keystone Kapers' sound effects
1987               	; 	' ======================================================================
1988               	; 	' A DIGIT PICKS THE CATEGORY, A LETTER PLAYS THE VARIANT. Press 4 for
1989               	; 	' PICKUP, then C and H and C again -- one key each, and the category stays
1990               	; 	' where it is. The ">" says which one is held.
1991               	; 	'
1992               	; 	' IT USED TO CYCLE, and cycling is fine for hearing a set once and useless
1993               	; 	' for the thing you actually do with it: A/B a PAIR over and over until one
1994               	; 	' of them is obviously right. Cycling makes you walk past everything in
1995               	; 	' between and lose the comparison on the way.
1996               	; 	'
1997               	; 	' LETTERS WORK BECAUSE THE TI RETURNS THEM. cont1.key on the TI-99/4A gives
1998               	; 	' uppercase ASCII from the keyboard as well as the stock 0-9 -- the keypad
1999               	; 	' digits come back as 0-9 and the letters as 65 upwards, so the two ranges
2000               	; 	' cannot collide. This was very nearly built on digits alone in the belief
2001               	; 	' that cont1.key was keypad-only; that is true of the ColecoVision and it
2002               	; 	' is not true here.
2003               	; 	'
2004               	; 	' ON COLECOVISION THERE IS NO KEYBOARD, so FIRE is kept as a way through
2005               	; 	' the variants of the held category. The bench is a TI tool in practice,
2006               	; 	' but a control scheme that silently does nothing on the other target is
2007               	; 	' not one worth shipping.
2008               	; 	'
2009               	; 	' Anything else is IGNORED -- an unknown key, a digit above 6, a letter
2010               	; 	' past the end of the category. Not clamped: a four-variant category does
2011               	; 	' nothing on E-J rather than quietly replaying its last one and leaving you
2012               	; 	' wondering whether you misheard.
2013               	; 	'
2014               	; 	' WHY IT EXISTS. The game's effects were hand-picked divisors that had
2015               	; 	' never been compared with anything. These are measured off an Atari 2600
2016               	; 	' recording (assets/sfxref.md has the workings and the method), and tuning
2017               	; 	' them by editing the game, rebuilding and playing to the right screen is
2018               	; 	' hopeless -- here it is a keypress.
2019               	; 	'
2020               	; 	' VARIANT A OF EVERY CATEGORY IS THE MEASURED ONE. The rest are departures
2021               	; 	' from it, so the reference is always one key away and the comparison is
2022               	; 	' never against memory.
2023               	; 	'
2024               	; 	' WHAT THE REFERENCE SAYS, and the first pass of the analysis got this
2025               	; 	' wrong in a way worth recording. Autocorrelation reported every effect as
2026               	; 	' noise, because the running sound plays underneath all of them and drags
2027               	; 	' the confidence of a pitch estimate down. Direct energy measurement at
2028               	; 	' fixed frequencies says otherwise: only the RUNNING and the TALLY ticks
2029               	; 	' are noise, and the pickup RISES where the hit FALLS -- which is the
2030               	; 	' difference between a reward and a penalty, and the thing the first pass
2031               	; 	' hid by filing both as "noise, about 660 ms".
2032               	; 	'

2367               	; 	' ----------------------------------------------------------------------
2368               	; 	' An effect is a run of FOUR-BYTE STEPS: frames to hold, which channel, a
2369               	; 	' value, and a volume. A step of 0 frames ends the effect; a step of 255
2370               	; 	' frames ends the whole table.
2371               	; 	'
2372               	; 	'     channel 0-2   a TONE. The value is the divisor over four, because a
2373               	; 	'                   divisor runs to 1023 and a DATA BYTE stops at 255.
2374               	; 	'                   Pitch is 3579545 / (32 * divisor), so a SMALLER
2375               	; 	'                   divisor is a HIGHER note -- sweeps read backwards from
