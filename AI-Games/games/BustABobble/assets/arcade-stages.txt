# BUST-A-BOBBLE -- the 30 arcade stage SHAPES, transcribed at the cell grid.
#
# PROVENANCE
#   Transcribed from the "PUZZLE BOBBLE STAGES and their MILLIONS" diagrams in the
#   Puzzle Bobble / Bust-A-Move FAQ v1.24 (neo-geo.com wiki). That FAQ draws each
#   round on the same 8/7 staggered grid the hardware uses, so the transcription is
#   cell-for-cell rather than by eye.
#
# WHAT IS AUTHENTIC AND WHAT IS NOT -- read this before "fixing" a level.
#   SHAPES are authentic: which cells hold a bubble, for all 30 rounds.
#   COLOURS ARE NOT, mostly. The FAQ's legend says:
#       a-d  colours; usually "attack spots" for earning millions
#       X    balls where you should find an "attack spot"
#       O    ball of ANY colour
#   So the source only pins down a colour where it matters strategically. Every O
#   and X is unspecified, and assets/transcribe_stages.py assigns those from the
#   round's stated palette with a deterministic banding pattern (see there).
#   The per-round COLOUR COUNT below is authentic.
#
#   Net: play these and you are playing the arcade's layouts with substituted
#   colours -- not a byte-exact reproduction of the arcade's bubbles. Replacing a
#   round with a screenshot-derived colouring only means editing this file.
#
# FORMAT
#   STAGE <n> <colour-count>
#   then the rows, top first. EVEN rows (1st, 3rd, ...) are 8 cells; ODD rows are
#   7 cells and sit half a cell right -- written indented one space, as on screen.
#   '.' empty   'O' any colour   'X' attack-spot marker (treated as O)
#   'a'..'d'    distinct named colours, preserved as distinct
