1985               	; 	' ======================================================================
1986               	; 	' COLECO SOUNDS -- a SECOND bench for Keystone Kapers' sound effects
1987               	; 	' ======================================================================
1988               	; 	' A separate app from `testsounds`, on purpose, so the two can be run
1989               	; 	' against each other. That one's candidates were measured off an ATARI
1990               	; 	' 2600 recording; these are measured off a COLECOVISION one.
1991               	; 	'
1992               	; 	' WHY THAT MATTERS MORE THAN IT SOUNDS. The ColecoVision runs the same
1993               	; 	' sound chip as this target -- a TI SN76489 at 3.579545 MHz -- so a
1994               	; 	' frequency read off the recording converts straight back to the register
1995               	; 	' the game wrote: divisor = 111860 / freq. The 2600's TIA is a different
1996               	; 	' chip with a 5-bit divider and its own waveform table, so every number
1997               	; 	' taken from it had to be re-imagined rather than translated. Here the
1998               	; 	' arithmetic is exact wherever the pitch is high enough to resolve.
1999               	; 	'
2000               	; 	' See games/KeystoneKapers/assets/sfx/sfxref-coleco.md for the measurements.
2001               	; 	'
2002               	; 	' A DIGIT PICKS THE CATEGORY, A LETTER PLAYS THE VARIANT. Press 3 for
2003               	; 	' FALL, then A and C and A again -- one key each, and the category stays
2004               	; 	' where it is. The ">" says which one is held.
2005               	; 	'
2006               	; 	' IT USED TO CYCLE, and cycling is fine for hearing a set once and useless
2007               	; 	' for the thing you actually do with it: A/B a PAIR over and over until one
2008               	; 	' of them is obviously right. Cycling makes you walk past everything in
2009               	; 	' between and lose the comparison on the way.
2010               	; 	'
2011               	; 	' LETTERS WORK BECAUSE THE TI RETURNS THEM. cont1.key on the TI-99/4A gives
2012               	; 	' uppercase ASCII from the keyboard as well as the stock 0-9 -- the keypad
2013               	; 	' digits come back as 0-9 and the letters as 65 upwards, so the two ranges
2014               	; 	' cannot collide. This was very nearly built on digits alone in the belief
2015               	; 	' that cont1.key was keypad-only; that is true of the ColecoVision and it
2016               	; 	' is not true here.
2017               	; 	'
2018               	; 	' ON COLECOVISION THERE IS NO KEYBOARD, so FIRE is kept as a way through
2019               	; 	' the variants of the held category. The bench is a TI tool in practice,
2020               	; 	' but a control scheme that silently does nothing on the other target is
2021               	; 	' not one worth shipping.
2022               	; 	'
2023               	; 	' Anything else is IGNORED -- an unknown key, a digit above 6, a letter
2024               	; 	' past the end of the category. Not clamped: a four-variant category does
2025               	; 	' nothing on E-J rather than quietly replaying its last one and leaving you
2026               	; 	' wondering whether you misheard.
2027               	; 	'
2028               	; 	' WHY IT EXISTS. Tuning an effect by editing the game, rebuilding, and
2029               	; 	' playing to the screen where it fires is hopeless; here it is a keypress,
2030               	; 	' and the two SOURCES can be A/Bed rather than argued about.
2031               	; 	'
2032               	; 	' VARIANT A OF EVERY CATEGORY IS THE MEASURED ONE. The rest are departures
2033               	; 	' from it, so the reference is always one key away and the comparison is
2034               	; 	' never against memory.
2035               	; 	'
2036               	; 	' HOW THE NUMBERS WERE GOT. `audioop.rms` over 10-20 ms blocks to find where
2037               	; 	' something happens, then a GOERTZEL FILTER PER CANDIDATE DIVISOR to say
2038               	; 	' what pitch it is. That asks a better question than an FFT peak-pick: not
2039               	; 	' "what frequency is this" but "of the divisors the chip can actually play,
2040               	; 	' which one is present", and the answer is the register value itself.
2041               	; 	'
2042               	; 	' AND THE LIMIT, WHICH MATTERS. Adjacent divisors sit about freq/divisor
2043               	; 	' apart, so at divisor 40 they are 70 Hz apart and trivially separated,
2044               	; 	' while at 212 they are 2.5 Hz apart and a 400 ms effect cannot resolve
2045               	; 	' them at all. Read a high note as a register value and a low one as a
2046               	; 	' neighbourhood. The recording also carries music and several channels at
2047               	; 	' once, so a reading is the LOUDEST thing in its window, not necessarily
2048               	; 	' the effect.
2049               	; 	'
2050               	; 	' WHAT THE RECORDING CANNOT SAY is which game event a sound belongs to. A
2051               	; 	' falling run recurs every fifteen to twenty seconds and fits a hit or a
2052               	; 	' prize equally well, so it is filed by SHAPE as category 3 and its exact
2053               	; 	' mirror is category 4. That pair is the one to judge: a fall and a rise are
2054               	; 	' the difference between a penalty and a reward.
2055               	; 	'
2056               	; 	' Dual target: TI-99/4A and ColecoVision, same SN76489 either way.
2057               	;

2391               	; 	' An effect is a run of FOUR-BYTE STEPS: frames to hold, which channel, a
2392               	; 	' value, and a volume. A step of 0 frames ends the effect; a step of 255
