; Keystone Kapers -- Kelly the Kop, THE CROUCH. Facing RIGHT.
;
; ONE FIGURE, THREE BANDS -- the same format as kelly-run1.txt and
; kelly-run2.txt, and read by the same loader:
;
;     rows  0-5    HELMET  '#'  black
;     rows  6-10   FACE    '-'  skin
;     rows 11-31   BODY    '0'  blue -- the squat, and its legs
;
; The grid is 16 wide by 32 tall. Any line that is exactly 16 of '.#-0' is read
; as art; everything else -- these ';' lines, blanks, the ruler -- is ignored,
; so annotate freely. THE INK MUST MATCH THE ROW: a TMS9918 sprite carries one
; colour, so a band IS a sprite and skin on row 12 is not available.
;
; IT USED TO BE THREE SEPARATE 16x16 GRIDS all drawn at the same y, overlapping,
; with the helmet winning shared pixels. That needed a reader of its own, a rule
; about which sprite won, and it cost THREE SPRITES on every scanline the figure
; touched -- the VDP counts sprite BOXES, not the ink in them. Staggering the
; boxes the way the run already does drops it to two, and makes the crouch an
; ordinary pose.
;
; THE HEAD IS THE STANDING HEAD, ROWS 0-10 OF kelly-run1.txt VERBATIM. The body
; squats and the head stays upright on top of it, which is what the reference
; does. Rows 0-10 are generated by copying that file, so "full size" is checked
; rather than judged -- and NO BLUE may appear in them, or the head reads as
; sunk into the body rather than sitting on it.
;
; THE HEIGHT IS LOAD-BEARING, AND THE BUDGET IS ONE LINE OF ARITHMETIC.
;
; A ball's hitbox is the middle 4 px of its art, so
;
;     duckable   when  ball >= DUCKH - 2
;     jumpable   when  ball <= apex  - 6
;
; and no ball height is NEITHER only while  DUCKH <= apex - 3.
;
; The jump apex is 14, so DUCKH may be at most 11 -- the windows are
; edge-to-edge with no slack, which is why 12 fails on a ball at exactly 9 px.
; assets/checkball.py sweeps every arc frame and says so. Raising the BOUNCE
; does not help: the arcs are parabolas sampled 32 times, so a higher peak still
; passes through every height on the way up and down. The two levers that work
; are the jump APEX (capped near 16 -- floors are 40 px apart and Kelly is 24,
; so 17 bonks the ceiling) and the ball hitbox THICKNESS; both at their limits
; give DUCKH <= 15.
;
; THIS FIGURE IS 17 PX. The head alone is 11 of them. Until those two constants
; move, DUCKDRAW (what he is drawn as) and DUCKH (what he collides as) differ,
; and a ball between them passes through his hat without hitting him.
;
; DRAW THE RIGHT-FACING CROUCH ONLY; the left is mirrored, the VDP having no
; flip bit. A pose that is its own mirror reads as the figure being SQUASHED
; rather than dropping and still looking where it is going -- assets/showduck.py
; prints how many pixels this differs from its own mirror.
;
;      0123456789012345
;      0000000000111111
